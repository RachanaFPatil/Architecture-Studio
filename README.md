# FORM & FRAME — Architecture Studio

A modern, responsive architecture studio website concept showcasing residential, renovation, and commercial architectural projects.

## Features
- Responsive homepage and navigation
- Project portfolio with category filters
- Individual project detail pages
- Image and video galleries
- Contact and project enquiry form
- Formspree integration for enquiry submissions

## Tech Stack
- React.js
- Vite
- JavaScript
- CSS
- Formspree

## Run Locally

Install dependencies:
```bash
npm install
```

Start development server:
```bash
npm run dev
```
Build for production:
```bash
npm run build
```
